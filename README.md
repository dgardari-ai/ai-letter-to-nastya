# Письмо об искусственном интеллекте для Анастасии Тен

Мобильная интерактивная статья, октябрь 2026. Один статический HTML-файл без внешних скриптов и сбора пользовательских данных.

Содержание: ИИ и изменение мира, реальные примеры железнодорожного бизнеса, интерактивные сценарии пассажира, три копируемых управленческих запроса, советы по безопасному использованию, ссылки на первоисточники.

Изображения: обработанный по поручению автора портрет, фотография из открытого фотобанка АО ТК «Гранд Сервис Экспресс» (указан правообладатель; https://grandtrain.ru/fotobank/), технология — Unsplash. Материал не представляет официальную позицию компании.

Для проверки достаточно открыть index.html в браузере. GitHub Pages публикует ветку main, каталог /.
